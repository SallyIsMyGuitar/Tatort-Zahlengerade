## Grundlegende Inhalte (ISB-Handreichung M9 I)

### Definition der Quadratwurzel
- Für a ≥ 0 ist √a die nichtnegative reelle Lösung der Gleichung x² = a. Beispiel: √16 = 4.
- x² = a hat für a ≥ 0 die Lösungen x = √a und x = −√a, also L = {−√a; √a}.
- Beispiele: x² = 9 → L = {−3; 3}; x² = 6 → L = {−√6; √6}.

### Rechnen mit Quadratwurzeln
- Alle Rechengesetze und Regeln für rationale Zahlen behalten ihre Gültigkeit.
- Produkt: √a · √b = √(a·b), z. B. √3 · √7 = √21.
- Quotient: √a : √b = √(a:b) für b ≠ 0, z. B. √32 : √8 = 2.
- √(a²) = |a| für alle a ∈ ℝ; (√3)² = 3.

### Teilweises Radizieren
- Quadratische Faktoren werden aus der Wurzel gezogen, z. B. √(72a³) = √(36 · a² · 2a) = 6a·√(2a) für a ≥ 0.

### Nenner rational machen
- Erweitern, sodass im Nenner keine Wurzel mehr steht, z. B. 5/√3 = 5√3/3.
